# 🏢 Topscore Consultants

Welcome to **Topscore Consultants** — a professional consultancy website built using **HTML, CSS, and JavaScript**.  
This repository contains the complete source code for the official Topscore Consultants website.

---

## 🌐 Overview

**Topscore** is a simple, elegant, and fully responsive static website designed to showcase consultancy services, company details, and contact information.

The site is organized into multiple sections and standalone pages such as:
- **Home Page** – brief introduction and hero section.
- **About Page** – company background and mission.
- **Services Page** – list of consulting services offered.
- **Contact Page** – contact details and inquiry form.

---

## 📁 Project Structure

```
topscore/
```

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rucomrada/topscore.git
```

### 2. Open the project
Open the folder in your code editor (e.g., VS Code).

### 3. Preview the website
You can open `index.html` directly in your browser, or use a local server for better performance:

```bash
# If you have Python installed:
python -m http.server
```
Then visit [http://localhost:8000](http://localhost:8000)

---

## 🧰 Optional – Using Prepros

If you want to use the Prepros build system:
1. Install [Prepros](https://prepros.io/)
2. Open this project folder inside Prepros.
3. It will automatically compile and minify CSS/JS as defined in `prepros-6.config`.
